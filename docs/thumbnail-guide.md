# サムネイル・画像作成〜組み込み手順書

ポートフォリオ内の作品サムネイルやWeb用画像を追加・差し替えする際の標準手順と運用ルールです。

---

## 1. 画像サイズ・容量・命名の目安

- **解像度（2倍サイズ基準）**
  - スマホやRetinaディスプレイ（高解像度画面）でぼやけないよう、**画面上の表示幅の約2倍**で用意します（例：横幅400pxのカードなら 800px〜1200px）。
  - 作品サムネイル（16:9）：**`1200 × 675`**
  - 画面いっぱいのメインビジュアル：PCは横幅 `1920px 〜 2400px` 程度（スマホ専用を分ける場合は `750px 〜 800px` 程度）
- **ファイル容量の目安**
  - WebP形式（画質 80〜85%）で、**1枚あたり 100KB 〜 300KB 以内**が理想です（1MB超は避ける）。
- **ファイル名ルール**
  - 半角英数字（小文字）とハイフン（`-`）のみ使用します（日本語・スペース・大文字混在はリンク切れの原因になるためNG）。
  - **良い例**：`work-01.webp`, `work-portfolio-01.webp`, `hero-pc.webp`
  - **悪い例**：`作品画像1.webp`, `Hero_Image(final).webp`

---

## 2. 作成〜組み込みステップ

### ステップ1：16:9 でスクリーンショットを撮る
1. 対象サイトを Chrome で開き、`F12`（Macは `Cmd + Option + I`）で開発者ツールを開く
2. 左上の **デバイスツールバー（スマホ・タブレットアイコン）** をクリック
3. 画面上部のサイズ指定に **`1440 × 810`**（または `1280 × 720`）と入力する
4. 右上の `⋮` メニュー ＞ **「スクリーンショットをキャプチャ」** で保存する

### ステップ2：Squoosh（Google製）でリサイズ＆WebP変換する
1. [Squoosh（squoosh.app）](https://squoosh.app/) を開き、スクショ画像をドラッグ＆ドロップする
2. 右パネルの **「Resize」** にチェックを入れ、以下を設定する
   - **Width（幅）**：`1200`
   - **Height（高さ）**：`675`
   - ※元の比率がわずかにズレている場合は「Maintain aspect ratio」のチェックを外す
3. 右パネルの **「Compress」** プルダウンから **`WebP`** を選ぶ（※ `WebP v2` は選ばない）
4. **「Quality（画質）」** を **`80 〜 85`** に調整する（文字が滲まない範囲で容量を落とす）
5. 右下のダウンロードボタンを押して保存する

### ステップ3：命名してフォルダに入れる
- 上記の命名ルールに沿ってリネームし、`public/images/` フォルダへ保存します（例：`public/images/work-01.webp`）。

### ステップ4：HTML に組み込む（`alt`・サイズ・遅延読み込み）
`<span>Screen Image (16:9)</span>` を以下の `<img>` タグに置き換えます。

```html
<div class="work-thumb">
  <img
    src="images/work-01.webp"
    alt="〇〇サイトのトップページ画面"
    width="1200"
    height="675"
    loading="lazy"
  >
</div>
```

- **`alt` の書き方**：下の見出しと重複しないよう、「〇〇サイトのトップページ画面」のように画面の内容を簡潔に書く
- **`width` / `height`**：元画像の縦横サイズ（`1200` / `675`）を必ず記述する。これにより読み込み中のレイアウト崩れ（CLS：レイアウトシフト）を防げます（実際の表示サイズはCSS側の `width: 100%; height: 100%; object-fit: cover;` で制御されます）。
- **`loading="lazy"` の使い分け**：
  - **ファーストビュー（開いてすぐ見える位置）の画像**：**つけない**（すぐ表示させたいため）
  - **スクロールしないと見えない下の方の画像**：**`loading="lazy"` をつける**（遅延読み込みさせて初期表示を速くする）
